# 数智学研智能体（CXY-Agent）

> CXY = 产（Industry）· 学（Academia）· 研（Research）
>
> 基于 AI Agent 技术，实时掌握专业领域产、学、研动态信息的智能体。
> 帮助学生从「只学课本知识」拓展到「了解真实产业发展、技术与实践场景」，
> 培养具有数字化、智能化视野的新一代大学生。

## 一、项目简介

数智学研智能体面向高校师生，持续采集**智能制造**领域的产学研动态，
把**产业进展、企业项目、技术研究成果**更快地引入课堂和实验室，
帮助学生建立**岗位认知、工程能力和创新意识**：

- **产**：追踪产业动向、标杆实践与岗位需求，帮助学生建立产业认知；
- **研**：追踪前沿论文、科研成果与技术转化，把最新进展引入课堂和实验室；
- **学**：追踪专业建设、课程改革与产教融合动态，服务学生学习与成长。

要解决的三个问题：

1. **解决「学用脱节」** —— 课堂学的和企业要的不完全一样，智能体把企业真实需求、行业标准和一线技术带进培养过程；
2. **让学生接触真实问题** —— 提前经历「需求 → 方案 → 验证 → 落地」的完整链条；
3. **提升就业竞争力** —— 充分理解产业需求的学生，更容易理解岗位要求，在简历和面试中体现与实际产业结合的能力。

## 二、基本原理

### 采集-评估-推送管线

```text
RSS 源 + Google News 检索式
        │  （检索式遵循 keyword.md 的「主体词 × 信号词」原则，见 config.yaml）
        ▼
① 时间窗口过滤（近 7 天）→ ② 多层去重（URL / 标题相似度 / 正文指纹 / 历史已推事件）
        ▼
③ DeepSeek 粗筛（仅标题+摘要，注入 keyword.md 当日板块上下文）
        ▼
④ 补抓候选正文 → 正文指纹去重（标题不同的转载稿）
        ▼
⑤ DeepSeek 四维价值终评（相关性/创新性/证据强度/可行动性，本地按权重重算总分）
   + 生成 event_key，同一事件合并为一张卡片，与近期已推事件跨次去重
        ▼
⑥ 中文摘要（面向学生，点明与产业实践/技术前沿/学习就业的关联）+ 周度趋势观察
        ▼
⑦ Markdown 落盘 output/ → PushPlus 推送微信 → 状态记录 state/（防重复推送）
```

### 核心机制

1. **关键词驱动的闭环采集** —— 基于 `keyword.md` 指定的关键字构成智能体的上下文，
   实现无人工干预的智能化逻辑闭环；用户只需维护 `keyword.md`，编辑保存后下次采集自动生效；
2. **多维度量化价值终评** —— 利用大模型从四个可调权重维度打分：
   相关性（30%）、创新性（25%）、证据强度（25%）、可行动性（20%），总分在本地按权重重算；
3. **内容去重与事件聚合** —— 标题不同但内容高度相似的文章只保留一篇；
   基于 `event_key` 将同一事件的多个参考来源聚合后推送。

信息线索与板块排期：

| 信息线索 | 关注内容 | 排期 |
| --- | --- | --- |
| 产 · 产业与实践 | 灯塔工厂、标杆企业、政策名单、产业信号 | 每周二 |
| 研 · 技术与科研 | 工业大模型、AI质检、预测性维护、机器人、工业软件 | 每周四 |
| 学 · 大学学习 | 专业培养动态、竞赛实训、岗位招聘、学习资源 | 每周六 |

## 三、如何部署

### 1. 环境准备

- Python 3.11+
- 两个密钥：
  - `DEEPSEEK_API_KEY` —— DeepSeek API 密钥（粗筛、终评、摘要）
  - `PUSHPLUS_TOKEN` —— PushPlus 推送 token（微信「推送加」公众号）

```bash
pip install -r requirements.txt
export DEEPSEEK_API_KEY=你的密钥
export PUSHPLUS_TOKEN=你的token
```

### 2. 本地验证

```bash
python -m cxy_agent.main --test-push                      # 只验证微信推送通道
python -m cxy_agent.main --category research --dry-run    # 手动跑「研」板块,不实际推送
```

### 3. GitHub Actions 自动运行

1. 把本仓库推到 GitHub；
2. 在仓库 **Settings → Secrets and variables → Actions** 添加 `DEEPSEEK_API_KEY` 与 `PUSHPLUS_TOKEN`；
3. 工作流按北京时间**周二/周四/周六 12:00** 自动运行对应板块，产出简报推送微信；
4. 每次运行后 `state/` 与 `output/` 自动提交回仓库，实现跨次去重与简报归档。

### 调整信息视野

- 改**关注什么**：编辑 `keyword.md`（由用户手工维护的采集关键字）；
- 改**怎么搜、推多少**：编辑 `config.yaml`（检索式、RSS 源、四维权重、阈值）。
